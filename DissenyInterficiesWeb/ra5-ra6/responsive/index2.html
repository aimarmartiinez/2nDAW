Disseny responsive amb media queries

Aquest layout s'adapta automàticament a tres mides: escriptori, tauleta i mòbil. Utilitzem CSS Grid amb àrees nomenades per reorganitzar el contingut segons l'amplada del dispositiu.

Suport per tema clar i fosc

Mitjançant la media query prefers-color-scheme, la pàgina detecta automàticament la preferència del sistema operatiu i aplica el tema corresponent sense necessitat d'interacció de l'usuari.

Estructura semàntica
