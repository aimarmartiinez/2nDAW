# Portfolio personal

Portfolio web creado para presentar proyectos y prácticas del ciclo de Desarrollo de Aplicaciones Web (DAW). La página de inicio incluye la presentación personal, información sobre mí y habilidades; el menú permite navegar por los trabajos de los módulos M06 (Entorno Cliente) y M09 (Diseño de Interfaces Web).

## Objetivo

Reunir en un único sitio una selección de ejercicios del ciclo y practicar cómo organizar y presentar una interfaz web mediante componentes y navegación entre páginas.

## Stack

- React y TypeScript
- React Router para la navegación entre las secciones
- React Bootstrap y Bootstrap Icons para los componentes y recursos visuales
- CSS para los estilos propios
- Vite como entorno de desarrollo

## Funcionalidades

- Página de inicio con presentación, información personal y habilidades.
- Secciones para las prácticas de M06 y M09.
- Navegación con enlaces y menús desplegables.
- Cambio entre tema claro y oscuro, con la preferencia guardada en `localStorage`.
- Tarjetas de prácticas con contenido multimedia en ventanas modales.

## Aprendizajes

- Crear componentes reutilizables con React y tipar sus propiedades con TypeScript.
- Organizar una aplicación de una sola página y definir rutas con React Router.
- Construir interfaces con React Bootstrap y adaptar sus estilos.
- Gestionar estado y efectos con hooks de React.
- Guardar preferencias del usuario en el navegador.
- Presentar proyectos y contenidos de forma clara y navegable.
