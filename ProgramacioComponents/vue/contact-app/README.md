# Contact App

Aplicació de gestió de contactes desenvolupada amb Vue 3. Permet gestionar contactes, grups, favorits, historial i estadístiques utilitzant una API simulada amb `json-server`.

## Tecnologies utilitzades

- Vue 3
- TypeScript
- Vite
- Vue Router
- Bootstrap 5
- json-server

## Qué hice

- CRUD complet de contactes amb grups, favorits i historial
- Validació de telèfon E.164 i detecció de duplicats
- Avatars auto-generats, cerca en temps real i estadístiques
- Scripts npm en paral·lel per arrencar frontend + json-server

## Stack

Vue 3, TypeScript, Vite, Vue Router, Bootstrap 5, json-server

## Aprendizajes

- Vue 3 Composition API: ref, computed, components reutilitzables
- Vue Router per navegació SPA
- Integració amb json-server com a API REST simulada
- Planificació per fases del projecte
- Bootstrap 5 dins d'un projecte Vue amb TypeScript
